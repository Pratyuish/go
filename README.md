# Go Learning Projects

This repository contains practical Go learning material and projects.

## Interactive Go Foundations website

The beginner course is located in [`learning-site/`](./learning-site).

It includes:

- Eight guided Go foundation lessons
- Editable code examples with learning-sandbox feedback
- Knowledge checks and mini challenges
- Progress tracking stored in the browser
- Quick references for syntax, types, and Go commands
- Responsive light and dark themes

### Run locally

```bash
cd learning-site
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

> The built-in browser sandbox simulates the bundled lesson examples. Use the official Go toolchain to compile arbitrary Go programs.
