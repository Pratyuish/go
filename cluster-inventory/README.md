# Cluster Inventory — Senior Go Interview Track

Five progressive, runnable exercises for platform-engineering interviews. Each directory contains a focused implementation and tests; study the prompt on the learning site, attempt your own version, then compare it with the checked-in reference.

```bash
go test ./...
go test -race ./...
```

The progression covers validation and deterministic output, consumer-owned interfaces, table-driven testing, bounded concurrency with cancellation, and a production-minded HTTP boundary.
